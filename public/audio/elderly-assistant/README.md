# تسجيلات مساعد كبير السن

ضع التسجيلات العربية الثابتة هنا بصيغة MP3 وبالأسماء التالية:

- `welcome.mp3`: أهلًا فيك، اختار كيف بقدر أساعدك.
- `service-question.mp3`: شو نوع الخدمة اللي بدك إياها؟
- `service-grocery.mp3`: شراء أغراض.
- `service-medicine.mp3`: شراء دواء.
- `service-medical-escort.mp3`: مرافقة طبية.
- `service-social-visit.mp3`: زيارة اجتماعية.
- `service-home-help.mp3`: مساعدة منزلية.
- `service-other.mp3`: خدمة أخرى.
- `location-question.mp3`: وين بدك الخدمة؟
- `timing-question.mp3`: متى بدك الخدمة؟
- `timing-immediate.mp3`: بأقرب وقت.
- `timing-scheduled.mp3`: بدي أحدد موعد.
- `details-question.mp3`: في تفاصيل إضافية بتحب تحكيلنا إياها؟
- `review-request.mp3`: راجع معلومات طلبك، وإذا صحيحة اضغط تأكيد.
- `edit-question.mp3`: شو بدك تعدّل؟
- `request-sent.mp3`: تم إرسال طلبك بنجاح.
- `request-cancelled.mp3`: تم إلغاء الطلب ومسح المعلومات.

إذا كان أي ملف غير موجود، تستخدم الواجهة نطق المتصفح تلقائيًا كبديل مؤقت.
